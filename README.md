# PpakAim

**Windows용 에임 테스트 및 사격 패턴 비교 프로그램**

PpakAim은 FPS 게임에서 사격 결과를 기록하고 감도·수직 배수 변경 전후를 비교할 수 있도록 설계된 도구입니다. 프로그램이 게임 설정을 자동으로 변경하지는 않습니다.

## 다운로드

**v1.0.0 설치 파일이 공개 배포되었습니다.** 아래에서 다운로드할 수 있습니다.

**[PpakAim-Setup.exe 직접 다운로드](https://github.com/gudtjr980-arch/PpakAim-Download/releases/download/V1.0.0/PpakAim-Setup.exe)**

[릴리스 전체 목록](https://github.com/gudtjr980-arch/PpakAim-Download/releases)

- 배포 파일: `PpakAim-Setup.exe` (GitHub에 실제 게시된 파일명)
- 대상 운영체제: Windows x64
- 형태: EXE 설치 프로그램
- 비용: 무료 배포
- 디지털 코드 서명: 없음

> GitHub 자산 등록 및 업로드된 원본과의 SHA-256 일치는 확인되었습니다. 다른 Windows PC에서 설치·동작 및 실제 게임 인식은 별도 검증이 필요합니다.

## 설치

1. 위 **Releases** 페이지에서 게시된 최신 설치 파일을 다운로드합니다.
2. [설치·파일 검증 안내](INSTALL.md)에 따라 파일의 SHA-256 해시를 확인합니다.
3. Windows에서 설치 파일을 실행하고 화면의 설치 절차를 진행합니다.
4. 프로그램을 실행해 사격 측정, 기록 저장·재조회 기능을 직접 확인합니다.

**보안 안내:** 코드 서명이 없어 '알 수 없는 게시자' 또는 SmartScreen 경고가 나타날 수 있습니다. 보안 프로그램이 악성코드라고 탐지하는 경우에는 경고를 무시하거나 보안 기능을 꺼서 실행하지 마세요. 파일 출처와 탐지 원인을 먼저 확인해야 합니다.

## 측정 데이터

개발용 원본 문서 기준, 프로그램은 측정 기록을 사용자 PC의 다음 위치에 저장하도록 설계되어 있습니다.

`%LOCALAPPDATA%\PpakAimDesktop\data\measurements.sqlite3`

배포 파일의 실제 동작, 업데이트 시 기록 유지, 외부 전송 여부는 정식 배포 전 별도로 검증해야 합니다. 업데이트 또는 재설치 전에 중요한 기록을 내보내거나 백업하세요.

## 문제 제보

설치 오류, 사용 중 문제, 개선 요청은 [Issues](https://github.com/gudtjr980-arch/PpakAim-Download/issues)에 남겨주세요. 문제가 발생한 Windows 버전과 오류 메시지를 첨부하면 확인에 도움이 됩니다. 개인정보·민감한 파일은 공개 이슈에 올리지 마세요.

이 저장소는 **설치 프로그램 배포 전용**이며 개발 소스코드는 포함하지 않습니다. GitHub의 자동 생성 파일인 Source code (zip/tar.gz)는 이 공개 저장소의 안내 문서만 담은 압축본으로, 설치 파일이 아닙니다.

## PUBG 및 UGC 훈련장 이용 주의사항

PpakAim은 사격 패턴과 감도 변화를 분석하기 위한 **외부 보조 프로그램**입니다. 게임 메모리 조작, 반동 자동 제어, 마우스 입력 주입 기능은 제공하지 않는 것으로 개발되어 있습니다.

다만 화면 캡처와 마우스 입력 측정 기능을 사용하므로, PUBG 운영 정책이나 안티치트 시스템에 의해 제한 또는 탐지될 가능성을 배제할 수 없습니다.

**PUBG UGC 훈련장에서 사용하더라도 PUBG/KRAFTON의 공식 승인이나 제재 면제를 의미하지 않습니다.** 다른 프로그램의 사용 사례 역시 허용의 근거가 되지 않습니다.

게임 이용약관 및 UGC 모드 규칙을 준수하고, 보안 차단·게임 경고가 나타나면 프로그램 동시 실행을 중단하세요. 보안 기능을 끄거나 탐지를 우회하는 행위는 권장하지 않습니다. 개발자는 게임 계정의 안전을 보증하지 않습니다.
