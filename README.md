# PpakAim

**Windows용 에임 테스트 및 사격 패턴 비교 프로그램**

PpakAim은 FPS 게임에서 사격 결과를 기록하고 감도·수직 배수 변경 전후를 비교할 수 있도록 설계된 도구입니다. 프로그램이 게임 설정을 자동으로 변경하지는 않습니다.

## 다운로드

**현재 첫 공개 배포 파일 등록 전입니다.** 설치 파일이 게시되면 아래 Releases 페이지에서 다운로드할 수 있습니다.

**[PpakAim 다운로드 · Releases](https://github.com/gudtjr980-arch/PpakAim-Download/releases)**

- 배포 파일: `PpakAim-Setup-v1.0.0.exe` (예정된 공개 파일명)
- 대상 운영체제: Windows x64
- 형태: EXE 설치 프로그램
- 비용: 무료 배포
- 디지털 코드 서명: 없음

> 실제 설치 파일이 Releases에 올라오기 전에는 다운로드가 가능하지 않습니다. 다른 Windows PC에서 설치·동작 및 실제 게임 인식은 별도 검증이 필요합니다.

## 설치

1. 위 **Releases** 페이지에서 게시된 최신 설치 파일을 다운로드합니다.
2. [설치·파일 검증 안내](INSTALL.md)에 따라 파일의 SHA-256 해시를 확인합니다.
3. Windows에서 설치 파일을 실행하고 화면의 설치 절차를 진행합니다.
4. 프로그램을 실행해 사격 측정, 기록 저장·재조회 기능을 직접 확인합니다.

**보안 안내:** 코드 서명이 없어 '알 수 없는 게시자' 또는 SmartScreen 경고가 나타날 수 있습니다. 보안 프로그램이 악성코드라고 탐지하는 경우에는 경고를 무시하거나 보안 기능을 꺼서 실행하지 마세요. 파일 출처와 탐지 원인을 먼저 확인해야 합니다.

## 측정 데이터

개발용 원본 문서 기준, 프로그램은 측정 기록을 사용자 PC의 다음 위치에 저장하도록 설계되어 있습니다.

`%LOCALAPPDATA%\PpakAimDesktop\data\measurements.sqlite3`

배포 파일의 실제 동작, 업데이트 시 기록 유지, 외부 전송 여부는 정식 배포 전 별도로 검증해야 합니다. 업데이트 또는 재설치 전에 중요한 기록을 내보내거나 백업하세요.
